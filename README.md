## 🎯 About This Repository

This repository is my personal **LeetCode + DSA practice log**.

Every problem I solve is organized into its own directory containing the solution and the corresponding LeetCode information.

The goal is not simply to increase the number of solved problems.

The real goal is to:

- Strengthen DSA fundamentals
- Recognize common problem-solving patterns
- Improve C++ implementation skills
- Develop better time and space complexity awareness
- Become more consistent at solving problems independently
- Build a long-term record of my DSA journey

> **Solve → Understand → Optimize → Repeat.**
